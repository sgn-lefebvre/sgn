# Révision SGN · M. Lefebvre

## Tester sur ton ordinateur

Ouvre `index.html` dans ton navigateur. Rien à installer.

## Relire avant de mettre en ligne

Les QCM et les situations : `data/ch01.js` à `data/ch04.js` (champs `q`, `c`, `r`, `e` ; les mini-cas ont un texte `s` et trois `questions`). Pour un contrôle automatique : `node sources/outils/verifier.js`.

## Le chapitre en cours en classe

Il est verrouillé : `verrouille: true` dans son fichier `data/chXX.js`. Les élèves voient le cadenas, mais ont accès au jeu et aux documents. Pour l’ouvrir à la fin du chapitre, supprime cette ligne (ou demande-le à Claude Code).

## Ajouter un TD

Range le fichier dans `documents/chXX/` (crée le dossier s’il n’existe pas), puis demande à Claude Code de l’ajouter au chapitre. Jamais de corrigé.

## Modifier le site

Ouvre Claude Code dans ce dossier et écris ta demande. Le fichier `CLAUDE.md` lui explique la structure et tes règles.

## Publier

Dans GitHub Desktop : un mot dans « Summary », « Commit to main », puis « Push origin ».
