# SGN · M. Lefebvre

## Tester sur ton ordinateur

Décompresse le dossier, puis ouvre `index.html` dans ton navigateur. Rien à installer.

## Relire avant de mettre en ligne

- Les QCM et les situations : `data/ch01.js` à `data/ch04.js` (champs `q`, `c`, `r`, `e`).
- Les synthèses : elles reprennent ton texte d'origine, seule la mise en forme change.

## Mettre en ligne avec Claude Code

Ouvre Claude Code dans ce dossier et demande :
« Initialise Git, crée un dépôt GitHub public sur mon compte personnel et active GitHub Pages. »

Le fichier `CLAUDE.md` lui explique la structure du site et la façon d'ajouter un chapitre.
